# 문의 접수 → 구글시트 + 이메일 설정 (최초 1회, 약 5분)

홈페이지 "견적 요청 / 문의 접수" 창에서 제출한 내용이 구글시트에 한 줄씩 쌓이고,
goodos@goodos.co.kr 로 알림 메일이 갑니다.

## 1. 구글시트 만들기
1. 구글 드라이브에서 새 스프레드시트를 만듭니다. (이름 예: `홈페이지 문의접수`)
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.

## 2. 스크립트 붙여넣기
1. 기본으로 있는 코드를 모두 지우고 `Code.gs` 내용을 붙여넣습니다.
2. 맨 위 `TOKEN` 값을 아무도 모르는 긴 문자열로 바꿉니다. (예: 영문+숫자 30자 이상)
   이 값은 3단계 환경변수에도 똑같이 넣습니다.
3. 저장(Ctrl+S).

## 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
2. 실행 사용자: **나**, 액세스 권한: **모든 사용자**
3. **배포** → 권한 승인 → 나오는 **웹 앱 URL** 을 복사합니다. (`https://script.google.com/macros/s/.../exec`)

> 메일 발송 권한(Gmail) 승인 화면이 나오면 허용해 주세요.

## 4. 홈페이지에 연결 (Vercel 환경변수)
Vercel 프로젝트 → Settings → Environment Variables 에 두 개를 추가하고 **재배포**합니다.

| 이름 | 값 |
|---|---|
| `GOOGLE_SHEET_WEBHOOK_URL` | 3단계에서 복사한 웹 앱 URL |
| `GOOGLE_SHEET_WEBHOOK_TOKEN` | 2단계에서 정한 TOKEN 과 같은 값 |

로컬 테스트는 프로젝트 루트에 `.env.local` 파일을 만들어 같은 두 줄을 넣으면 됩니다.

## 확인
홈페이지에서 문의를 한 번 제출해 보세요. 시트에 `문의접수` 탭이 자동 생성되고 한 줄이 추가되며,
메일이 도착하면 성공입니다. 시트의 마지막 열 `처리상태` 는 직접 "연락완료" 등으로 관리하세요.

## 참고
- Code.gs 를 수정한 뒤에는 **배포 → 배포 관리 → 새 버전** 으로 다시 배포해야 반영됩니다.
- 메일 하루 발송 한도(일반 계정 약 100통) 안에서 동작합니다. 시트 기록은 한도와 무관합니다.
